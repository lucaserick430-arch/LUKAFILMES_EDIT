SERIE — PAGINA INDIVIDUAL

Arquivo:
paginas/serie.html

Esta pagina e aberta depois que o usuario escolhe uma serie.

A serie e salva em:
localStorage.setItem("serieSelecionada", JSON.stringify(serie))

A pagina individual recupera:
localStorage.getItem("serieSelecionada")

e depois:
JSON.parse(salvo)

Foi confirmado que a pagina individual possui logica para backdrop:

let fundo = "";

if (serie.fundo) {
    fundo = serie.fundo;
} else if (serie.backdrop_path) {
    fundo = "https://image.tmdb.org/t/p/w1280" + serie.backdrop_path;
}

Depois:
document.documentElement.style.setProperty(
    "--fundo-serie",
    'url("' + fundo + '")'
);

O CSS utiliza:
var(--fundo-serie)

Portanto a pagina individual ja sabe trabalhar com backdrop_path.
